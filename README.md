FutureTrack

FutureTrack is a web-based enrollment and career guidance system designed for incoming Grade 7 students of Dayap National Integrated High School (DNIHS).

The system aims to provide a more convenient and organized enrollment experience while helping students explore possible career paths based on their interests.

Features

- Web-based enrollment interface
- Student information management
- Enrollment progress tracking
- Career guidance integration
- Responsive and modern user interface
- Interactive dashboard

Technologies Used

- HTML
- CSS
- JavaScript
- GitHub Pages

Purpose

FutureTrack was developed as a school research and system development project to explore how a web-based platform can improve the enrollment process and provide career guidance for incoming students.
